# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in stackdiag, please report it responsibly.

**Email:** security@stackdiag.dev

Please include:

- Description of the vulnerability
- Steps to reproduce
- Potential impact

## Response Timeline

- **Acknowledgment:** Within 48 hours
- **Initial assessment:** Within 1 week
- **Fix timeline:** Depends on severity, typically within 2 weeks for critical issues

## Scope

stackdiag is a diagnostic CLI tool that makes outbound network connections. Security concerns include:

- Information disclosure through output
- Command injection via user inputs
- Credential leakage in logs or output

## Preferred Contact

Please use email rather than public GitHub issues for security reports.
